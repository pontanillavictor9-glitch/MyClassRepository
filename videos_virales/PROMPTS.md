# Prompts para Higgsfield — Serie "ASMR imposible"

## Cómo usarlos

1. Copia UN prompt entero (el bloque en inglés) y pégalo en Higgsfield.
2. Formato: **vertical 9:16**, duración 5-10 s. Si el modelo lo permite (Veo 3), activa el audio.
3. Descarga el clip y guárdalo en la carpeta `clips/` con el número del prompt
   (ej. `clip_01.mp4`). Si un clip sale mal, regenera — no lo guardes.
4. Los prompts están en inglés porque los modelos de vídeo obedecen mejor en inglés.

Todos comparten el mismo estilo para que el canal tenga identidad. La frase de estilo
común ya va incluida dentro de cada prompt.
